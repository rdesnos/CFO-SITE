# CFO Marine — Espace cognitif

Ce répertoire réunit le prototype « Chemins de mémoire », sa doctrine UX et le protocole de conception.

## Accès
- [Prototype interactif](./index.html) — HTML autonome à ouvrir dans un navigateur ; pas encore confirmé comme déployé sur chroniques-fille-ordinaire.com.
- [Principes UX transversaux](./principes-ux.md)
- [Protocole Dalida](./protocole-dalida.md)

## Périmètre actuel
- Troubles cognitifs liés à la mémoire, sans classification des personnes par pathologie.
- Initiative de la sollicitation confiée à un accompagnant.
- L'accompagnant renseigne des références culturelles et des repères connus, choisit une proposition, puis peut faire une pause ou terminer.
- La mémoire collective est utilisée comme réservoir de contenus ; aucune réaction n'est exigée ou notée.
- Attention à l'inconstance des capacités et des réactions : l'interface garde des repères stables.
- Respect, consentement, autonomie, protection de la vie privée.
- Éviter le terme « démence » dans la communication du projet.

## État de réalisation
Le prototype est une démonstration HTML/JS autonome. Les propositions ne sont pas encore raccordées à une base culturelle vérifiée, aucune musique n'est intégrée et son efficacité pour les personnes concernées n'est pas établie. Il ne recueille pas de données personnelles.

**Attention déploiement :** ajouter des fichiers sur GitHub n'établit pas que l'hébergeur WordPress sert directement /cognitif/. Vérifier ce point avant d'annoncer une URL publique.
