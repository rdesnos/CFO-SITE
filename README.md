# CFO Agenda

Plugin WordPress autonome pour afficher les événements CFO en 4 vues :
- Année
- Trimestre
- Mois
- Semaine

## Shortcode
`[cfo_agenda]`

Attributs :
- `artist="marine"`
- `view="year|quarter|month|week"`
- `types="live,radio,press,collaboration"`
- `title="Agenda"`

Source : RPC Supabase `public.cfo_agenda_events`.
