## Vérifications

Vérifications du rendu DOM avec les réponses actuelles des services publics :
- Julien : valeurs, source, dates individuelles, relevés anciens et état hors connexion.
- Joffrine : trois œuvres, chronologie, onglets.
- Philypa : sept crédits, quatre contenus, dates de détection identifiées, agenda vide explicite.
- Marine : audience Spotify 906 833 dans le relevé utilisé, quatorze états de sources, cinquante et un points de graphiques.
- Magimel : vingt-huit films dans le périmètre 2012–2026 de l’Académie des César, recherche et menu.

La vérification visuelle dans un navigateur n’a pas pu être exécutée dans cet environnement. Les correctifs Marine, Julien Lieb et Philypa sont désormais servis par leurs sites publics.

Le service public de panel dépassait le délai SQL autorisé. Un cache en base, alimenté par la tâche horaire existante, remplace le calcul à chaque visite. Les dates d’observation d’origine sont conservées.

## Blocages précis

Les trois sites publics chargent leurs nouveaux scripts. Les fichiers répondent HTTP 200 avec les correctifs de dates et de restitution des données.

Il a refusé le transfert et le chargement public du portrait privé de Magimel faute d’autorisation explicite pour ce fichier. Le script sauvegardé dans le dépôt ne charge pas ce portrait.

L’aperçu privé complet de Magimel est disponible pour examen. Aucune mise en ligne du domaine Magimel n’est revendiquée.
