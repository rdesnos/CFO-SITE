# CFO Hebdo - couverture N°001 - référence validée

Validation : 22 septembre 2026

## Statut
Cette composition est la référence visuelle validée pour la couverture du premier CFO Hebdo.

## ADN
- Magazine artistique, glamour et éditorial, jamais institutionnel.
- Traitement illustré / BD / dessin de presse, pas de portrait photoréaliste généré par IA.
- Les personnalités réelles doivent rester reconnaissables : référence réelle d'abord, stylisation ensuite.
- Palette CFO : papier/ivoire, bleu profond, rouge brique, accents dessinés.
- Grande présence centrale + contrepoints de couverture.

## Composition de référence
- Masthead : CFO.
- Signature : L'HEBDO ARTISTIQUE.
- Sujet principal : Adèle Exarchopoulos.
- Accroche : « Ces femmes qui changent la donne ».
- Contrepoints : Marine / Julien Doré / Bonnard.
- Marine conserve un traitement volontairement différent, plus incarné.
- Julien Doré et Bonnard utilisent STRICTEMENT le même gabarit d'image : même largeur, hauteur, ratio, cadrage, alignement et poids visuel.

## Règle de configuration
Toute future variante doit partir de cette référence et non recréer la couverture depuis zéro.
La structure, le rythme, le contrepoint et la grille des vignettes secondaires sont considérés comme validés.
