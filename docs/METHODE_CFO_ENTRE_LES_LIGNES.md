# Méthode CFO — Doctrine « Entre les lignes »

Version figée : 2026-09-03

## 1. Rôle dans le système CFO

« Entre les lignes » est le cœur éditorial de CFO. Chaque dossier part d’une chanson, d’un motif ou d’un élément de l’œuvre de Marine pour ouvrir vers une question humaine, sociale, culturelle ou de société.

Le principe directeur est : **intelligence d’abord**.

Le dossier doit permettre au lecteur de :

1. comprendre l’histoire ou le sujet ;
2. distinguer les faits établis des interprétations ;
3. vérifier les éléments importants ;
4. approfondir le sujet au-delà de l’article CFO.

## 2. Doctrine éditoriale

### 2.1. Partir de l’œuvre

Le point d’entrée reste toujours l’œuvre : chanson, parole, entretien, contexte de création, scène ou élément documenté lié à Marine.

Le sujet général vient ensuite. CFO ne plaque pas artificiellement un thème sur une chanson : le lien entre l’œuvre et le sujet doit être explicite, honnête et documenté.

### 2.2. Sourcer au maximum

Doivent être sourcés autant que possible :

- citations directes ;
- propos rapportés ;
- faits biographiques ;
- chiffres et statistiques ;
- éléments médicaux, juridiques, sociaux ou institutionnels ;
- dates et événements ;
- affirmations attribuées à un média, un artiste, une institution ou une étude.

Les éléments d’analyse ou d’interprétation CFO doivent être présentés comme tels et ne jamais être confondus avec un fait établi.

### 2.3. Notes dans le corps du texte

Le système de référence standard est une **note numérotée dans le texte**, sous forme d’appel discret : `[1]`, `[2]`, `[3]`, etc.

Aucune source longue ne doit encombrer directement le corps de l’article.

Les appels de note doivent idéalement être cliquables vers la référence correspondante en bas de page.

### 2.4. Notes et références en bas de page

Chaque dossier comporte une section obligatoire **« Notes et références »**.

Chaque note doit contenir, lorsque disponible :

- numéro de note ;
- nom de la source ou de l’organisme ;
- titre du contenu ;
- auteur ;
- date de publication ;
- lien direct vers la source ;
- précision utile sur ce que la source documente dans le dossier.

Lorsqu’un système d’ancres est utilisé, chaque note comporte un lien de retour vers l’appel de note dans le texte.

### 2.5. Citations

Toute citation directe doit avoir une provenance identifiable.

Le rendu visuel standard CFO des citations comprend :

- citation en retrait ;
- filet vertical couleur tuile CFO ;
- typographie éditoriale cohérente avec la charte ;
- appel de note visible et discret ;
- référence détaillée uniquement dans « Notes et références ».

Une citation sans source identifiable n’est pas publiée comme citation directe.

## 3. « Aller plus loin » : composant obligatoire

Après « Notes et références », chaque dossier comporte une section **« Aller plus loin »** riche et réellement utile.

Cette section n’est pas une duplication des références. Sa fonction est d’aider le lecteur à approfondir le sujet.

Elle peut contenir :

- sources institutionnelles ;
- rapports publics ;
- études ou publications de référence ;
- associations spécialisées ;
- ressources d’aide ;
- livres ;
- podcasts ;
- documentaires ;
- interviews longues ;
- articles de fond ;
- ressources pédagogiques ;
- organismes de référence.

La sélection doit être éditorialisée : chaque lien doit avoir une raison d’être et, lorsque cela aide le lecteur, une courte indication de son intérêt.

Principe à retenir :

> **Les Notes et références prouvent ce que CFO écrit ; Aller plus loin permet de poursuivre le sujet.**

## 4. Structure standard d’un dossier

Ordre de référence :

1. bandeau CFO ;
2. titre du dossier ;
3. métadonnées : date / rubrique « Entre les lignes » / temps de lecture ;
4. illustration éditoriale principale ;
5. légende ;
6. chapô ;
7. développement éditorial ;
8. citations sourcées ;
9. intertitres ;
10. conclusion ;
11. Notes et références ;
12. Aller plus loin ;
13. Poursuivre la lecture vers d’autres dossiers CFO.

## 5. Doctrine visuelle

Le gabarit « Entre les lignes » est commun à tous les dossiers.

Éléments figés :

- bandeau bleu CFO avec liseré tuile ;
- largeur éditoriale resserrée ;
- métadonnées compactes ;
- illustration principale unique, centrée et non déformée ;
- légende proche de l’image ;
- chapô fort ;
- intertitres homogènes ;
- citations avec filet tuile ;
- rythme vertical régulier ;
- aucune duplication d’image vedette / image de contenu ;
- même comportement responsive pour les neuf dossiers.

Une modification de ce gabarit doit être considérée comme une modification d’un composant figé CFO et doit suivre le cycle de validation de configuration.

## 6. Règles de qualité

Avant validation d’un dossier :

- aucune citation directe sans note ;
- aucune donnée sensible ou factuelle importante sans source lorsque la source existe ;
- aucune source douteuse utilisée lorsque de meilleures sources primaires ou institutionnelles sont disponibles ;
- aucune confusion entre fait, hypothèse, signal et interprétation ;
- aucune image déformée ou dupliquée ;
- aucune incohérence avec le gabarit de référence ;
- section « Notes et références » présente ;
- section « Aller plus loin » suffisamment fournie ;
- liens vérifiés ;
- responsive contrôlé.

## 7. Hiérarchie des sources

Ordre de préférence :

1. source primaire : artiste, label, producteur, organisme officiel, étude originale ;
2. source institutionnelle ou scientifique ;
3. média reconnu ayant réalisé l’interview ou le reportage ;
4. média secondaire de qualité ;
5. agrégateur ou source indirecte uniquement lorsque la source primaire n’est pas accessible et avec prudence.

Pour les sujets médicaux, juridiques, sociaux ou de sécurité, privilégier systématiquement les sources institutionnelles et organismes spécialisés.

## 8. Gestion de configuration

Le gabarit « Entre les lignes » est un composant CFO figé après validation visuelle.

Cycle obligatoire :

1. modification en préproduction ;
2. contrôle du rendu réel ;
3. comparaison avec la baseline visuelle ;
4. validation explicite de Rudy ;
5. publication en production ;
6. contrôle post-production ;
7. commit Git de la version validée.

Une modification d’un autre chantier ne doit pas modifier implicitement ce composant.
