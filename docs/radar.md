# Le Radar — spécification V1

**Promesse : Ce qui se passe. Ce qui bouge. Ce qu’on surveille.**

Le Radar est le chantier technico-éditorial en cours. Il doit devenir le pont entre la veille, les données, l’éditorial et L’Observatoire.

## Trois niveaux

### Actualités

Faits confirmés et sourcés : sortie, concert, interview, collaboration, classement, certification, passage média ou autre événement vérifiable.

### À surveiller — signal faible

Évolution inhabituelle qui mérite d’être suivie mais ne permet pas encore de conclure : accélération d’audience, nouvelle proximité artistique, activité sociale émergente, nouvel environnement éditorial, etc.

Un signal faible n’est ni une information acquise ni une prédiction.

### Signal fort

Changement significatif, événement majeur ou convergence de plusieurs éléments indépendants justifiant une qualification plus forte.

## Chaîne cible

Sources → collecte → normalisation → détection → qualification → validation → diffusion

La détection automatique peut faire remonter un élément mais ne décide pas seule de sa publication.

## Principe éditorial

Toujours distinguer :

- le fait observé ;
- le signal détecté ;
- l’interprétation CFO ;
- le niveau de confiance ;
- les sources.

Un élément validé pourra alimenter Le Radar public, un article, une analyse, L’Observatoire ou une trajectoire MGP.
